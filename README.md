# South Africa: Electricity Access and CO2 Emissions

Analysis of the relationship between electricity access and CO2 emissions
per capita in South Africa, using World Bank data.

## Project structure
- `data/` : World Bank datasets (CO2 emissions per capita, access to electricity)
- `notebooks/` : Jupyter notebook with the analysis (`analysis.ipynb`)

## How to run
1. Install Python and Jupyter
2. Open `notebooks/analysis.ipynb`
3. Run all cells

## Data sources
- World Bank: CO2 emissions (metric tons per capita)
- World Bank: Access to electricity (% of population)
